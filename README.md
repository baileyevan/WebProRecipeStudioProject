# MealForge

MealForge is a responsive recipe browsing web application built with HTML and CSS.
It allows users to explore recipes, filter by category, and view detailed cooking instructions in a clean, modern interface.

## Project Overview
MealForge is a static recipe website designed to demonstrate core HTML and CSS concepts including responsive layouts, semantic markup, and CSS-based interactivity.

The website allows users to:
- Browse a collection of recipes
- Filter recipes by category
- View detialed ingredient lists and instructions


## Features

- Responsive navigation menu
- CSS-Only recipe filtering system
- Flexbox-based layout
- Styled recipe detail pages
- Consistent color system using CSS variables
- Mobile-friendly layout
